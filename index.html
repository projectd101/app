Set it up once, then get updates and the news behind them with just 2 or 3 clicks, all personalized for you. No more checking hundreds of sites. Click anywhere, on the desktop, on any window, in any app, while you’re doing anything.

Open Terminal (⌘ Space, type Terminal), paste this, press Return:

curl -fsSL https://github.com/projectd101/app/releases/latest/download/Tokr.dmg -o /tmp/Tokr.dmg && hdiutil attach /tmp/Tokr.dmg -nobrowse -quiet && cp -R /Volumes/Tokr/Tokr.app /Applications/ && hdiutil detach /Volumes/Tokr -quiet && rm /tmp/Tokr.dmg && open -a Tokr
